# 延讯(YX)转供应商发票 — 功能规格文档

> 最后更新: 2026-10-17 | 维护者: berry-bi

## 1. 功能概述

**延讯标准模板转供应商**（`/yx-to-tiantu`）把延讯客户已转成**易通标准模板**的下单发票，自动转换为指定供应商的发票模板。

输入源（易通标准模板）正是 `yanxun-convert`（延讯下单优化）的输出格式，两者串接即完成「延讯发货单 → 易通标准模板 → 供应商发票」的完整链路。

- **输入**: 易通标准模板（`.xlsx`，sheet `ETTON电商物流 下单模板`）
- **界面输入**:
  - 供应商（下拉：天图 / 星链 / 皓鹏 / 美琦 / 安邦；安邦暂未提供模板，禁用）
  - 服务渠道（下拉：按所选供应商从模板渠道表解析，切换供应商自动刷新）
  - 客户订单号（**可选**；批量时留空 → 输出文件名回退为源文件名 / FBA 前缀）
- **输出**: 单张 `<客户订单号>.xlsx`（单文件）或 `.zip`（批量，含每份供应商发票 + `_summary.json` 汇总）

## 2. 输入格式

同 LS 的易通源共享解析（sheet `ETTON电商物流 下单模板`），顶部字段与明细列见 `ls-to-supplier.md` §2.1。本功能额外用到：清关方式 B11、收件人国家 F9、仓库代码 F10、带电 F2、带磁 F3、报关方式 B8。

## 3. 供应商清单与渠道解析

| 供应商 | 模板文件（`public/templates/suppliers/`） | 主 sheet | 数据区起始 | 渠道字段 | 渠道清单来源 |

| 皓鹏 | `模板转换/皓鹏-模板.xls` → 已转 `皓鹏-模板.xlsx` | `单票下单-填写表` | R19（20 列）| B1 服务 | `2026.8.27 服务渠道表` C 列 |

## 4. 输出映射

### 4.1 天图（sheet `Sheet1`）

**顶部**：B1=渠道，B2=仓库代码（源 F10），B11=收件人国家代码（源 F9 中文国名 → 二字代码，未知透传），B14=客户订单号，B16=带电（有值才写），B17=带磁（有值才写），B18=交税方式（`无`/空 → `包税`，其余透传），B19=报关方式（`普通报关` → `托管报关`，其余透传），B22=总箱数（源 B18）。

**明细（R30 起 18 列）**：`[boxId, refId, nameEn, nameCh, unitPrice, totalQty, totalPrice, material, hsCode, use, brand, model, image, link, grossWeight, L, W, H]`。

### 4.2 星链（sheet `美中北`）

**顶部**：B4=boxId（首行），B5=refId（首行），B6=渠道，B7=countryCode，B9=报关类型（`无单证`→`不需报关`，`报关退税`/`普通报关`→`单独报关`，含 `合并`→`合并报关（两票及以上需要合并单独报关的）`），B10=`否`，B11=`不投保`，F12=仓库代码。

**明细（R18 起 20 列）**：`[序号(i+1), boxId, refId, nameCh, nameEn, netWeight, totalQty, unitPrice, "USD", material, use, hsCode, grossWeight, L, W, H, image, hasBattery, hasMagnet, link]`。

### 4.3 皓鹏（sheet `单票下单-填写表`）

**顶部**：B1=渠道，B2=仓库代码，B10=countryCode，B13=客户订单号，B14=总箱数，F5=报关方式（`报关退税`→`单证报关`，`普通报关`→`非单证报关`，其余透传），F6=交税方式，F7=币种（`yxCurrencyFor` 映射），F13=refId（首行）。

**明细（R19 起 20 列）**：`[订单号/FBA前缀 + U + 6位序号, nameEn, nameCh, totalQty, "个", unitPrice, grossWeight, L, W, H, hsCode, brand, material, model, use, link, image, netWeight, sku, refId]`。

### 4.4 美琦（sheet `发票`）

**顶部**：B1=客户订单号，B2=客户订单号，B3=渠道，B4=仓库代码，B14=带电，B15=带磁，B16=报关方式，B17=总箱数，E1=交货站点（默认`清溪仓`），E2=预计提货时间（今天，日期格式 `yyyy-mm-dd`），E3=`上门提货`。

**明细（R19 起 18 列）**：`[货箱编号（累计起-止，如 `1-7`）, nameEn, nameCh, 单箱数量, unitPrice, grossWeight, L, W, H, hsCode, brand, material, model, use, image, refId, boxCount, boxId]`。A 列「起-止」为**同一个 FBA 货件（货件追踪编码 refId 相同）内**的累计箱号范围：起始=同组前序累计+1，止=起始+boxCount-1；**换一个新的货件追踪编码时重新从 1 起**（如 `1-30`、`31-60` 后换单号变 `1-10`）。

## 5. 批量上传

- 一次可上传多份易通发票（`<input multiple>`）。
- **校验**：所有源文件收件人国家一致，否则返回 400（提示「批量转换仅支持同一国家的发票」）；渠道由界面统一选择填入。
- 输出 ZIP：每份供应商发票在根目录，同名时追加 `(1)`/`(2)` 去重；附 `_summary.json` 汇总（supplier / country / files）。
- 客户订单号批量时留空，输出文件名回退为源文件名（去扩展名）。

## 6. 非目标 / 已知限制

- **品名去重后缀 `-1`**：当天图发票内存在相同「英文品名 + 单价 + 数量」重复行时，答案模板会手动给后续行加 `-1` 后缀，但样本规则不一致，无法可靠推导，故**不做后缀去重**，如实透传品名。此类行需人工复核。
- **浮点尾差**：源 J 列总价带浮点尾差，已通过 `toPrecision(15)` 对齐 Excel 的 15 位有效数字存储精度。
- **星链默认 sheet `美中北`**：星链模板含多个结构相同的地区 sheet（美中南/美西/美东北/美东南），当前固定取 `美中北`，如需按国家自动选 sheet 需后续扩展。
- **皓鹏模板由 `.xls` 转 `.xlsx`**：转换保留 sheet 名、值、示例数据行，但边框/列宽等格式可能部分丢失；数据行填充时统一补边框（复用天图做法）。皓鹏收件人字段（B3/B4/B5…）为模板硬编码示例值，未做替换，需人工核对。
- **安邦无模板**：本次跳过，页面占位。
