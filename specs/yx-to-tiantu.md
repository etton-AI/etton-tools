# 延讯(YX)转天图供应商发票 — 功能规格文档

> 最后更新: 2026-10-17 | 维护者: berry-bi

## 1. 功能概述

**延讯标准模板转天图**（`/yx-to-tiantu`）把延讯客户已转成**易通标准模板**的下单发票，自动转换为供应商「**天图**」发票模板。

输入源（易通标准模板）正是 `yanxun-convert`（延讯下单优化）的输出格式，两者串接即完成「延讯发货单 → 易通标准模板 → 天图发票」的完整链路。

- **输入**: 易通标准模板（`.xlsx`，sheet `ETTON电商物流 下单模板`）
- **界面输入**: 客户订单号（如 `YXMY26090028`，必填）、服务渠道（如 `美转加加西19日达-卡派-BS`，必填，带常用渠道下拉）
- **输出**: 单张 `<客户订单号>.xlsx` 天图发票

## 2. 输入格式

同 LS 的易通源共享解析（sheet `ETTON电商物流 下单模板`），顶部字段与明细列见 `ls-to-supplier.md` §2.1。本功能额外用到：清关方式 B11、收件人国家 F9、仓库代码 F10。

## 3. 输出映射 — 天图发票

模板：`public/templates/suppliers/天图-模板.xlsx`（sheet `Sheet1`）。

### 3.1 顶部字段

| 目标 | 值来源 |
|------|--------|
| B1 服务 | 界面「服务渠道」 |
| B2 仓库代码 | 源 F10（触发模板 VLOOKUP 带出地址） |
| B11 收件人国家代码 | 源 F9 中文国名 → 二字代码（`加拿大→CA` / `美国→US` 等，未知则透传） |
| B14 客户订单号 | 界面「客户订单号」 |
| B16 带电 | 源 F2（有值才写） |
| B17 带磁 | 源 F3（有值才写） |
| B18 交税方式 | 源清关方式 `无` 或空 `→ 包税`，其余透传 |
| B19 报关方式 | `普通报关 → 托管报关`，其余透传 |
| B22 总箱数 | 源 B18 |

### 3.2 数据区（从 R30 起，18 列）

| 列 | 字段 | 值来源 |
|----|------|--------|
| A | 货箱编号 | 源 A |
| B | PO Number | 源 B（货件追踪编码） |
| C | 英文品名 | 源 C |
| D | 中文品名 | 源 D |
| E | 单个申报单价 | 源 I（15 位有效数字对齐 Excel） |
| F | 单箱申报数量 | 源 H |
| G | 单箱申报总价 | 源 J（15 位有效数字对齐 Excel） |
| H | 材质 | 源 E |
| I | 海关编码 | 源 L（文本） |
| J | 用途 | 源 F |
| K | 品牌 | 源 M |
| L | 型号 | 源 N |
| M | 图片链接 | 源 V（`0` 或空 → 数值 0） |
| N | 销售链接 | 源 U（`0` 或空 → 数值 0） |
| O | 货箱重量 | 源 Q |
| P/Q/R | 长/宽/高 | 源 R/S/T |

## 4. 输出

单张天图发票以 `<客户订单号>.xlsx` 命名（`sanitizeFileName` 去掉非法文件名字符）。

## 5. 非目标 / 已知限制

- **品名去重后缀 `-1`**：当天图发票内存在相同「英文品名 + 单价 + 数量」重复行时，答案模板会手动给后续行加 `-1` 后缀（如 `Night light` → `Night light-1`）以区分，但样本中该规则不一致（有的只给第 2 个重复行加、有的给所有重复行加），无法从易通标准模板可靠推导，故本功能**不做后缀去重**，如实透传品名。此类行需人工复核。
- **浮点尾差**：源 J 列总价带浮点尾差（如 `25.759999999999952`），已通过 `toPrecision(15)` 对齐 Excel 的 15 位有效数字存储精度（`25.76`），避免与答案不一致。
