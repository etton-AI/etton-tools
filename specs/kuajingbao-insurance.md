# 跨境堡批量投保 — 功能规格文档

> 最后更新: 2026-09-16 | 维护者: berry-bi

## 1. 功能概述

**跨境堡批量投保**（`/kuajingbao-insurance`）将「系统导出的货箱清单」按 SO 号（系统SO）自动聚合，填充「跨境堡批量投保箱单模版」，消除手动整理货物描述、货值、币种、备注的重复劳动。

- **输入**: 系统导出的货箱清单 Excel（`.xlsx` / `.xls`，Sheet1，含「系统SO」+「中文品名」表头）
- **输出**: `{原文件名}_跨境堡投保箱单.xlsx`，主 sheet「批量导入投保数据」逐票（SO）一行

## 2. 输入格式 — 系统货箱清单

表头行需同时含「系统SO」和「中文品名」（前 10 行内自动定位）。关键列按表头关键词 `startsWith` 匹配：

| 货箱清单列 | 关键词 | 用途 |
|-----------|--------|------|
| 系统SO | 系统SO / SO | 分组主键（仅每组首行有值，续行向下填充） |
| 工作号 | 工作号 | 仅展示/排查 |
| 国家 | 国家 | → 目的国 |
| 仓库代码 | 仓库代码 | → 目的地 / 备注中的 AAAA |
| FBA ID | FBA ID / FBA | → 入仓编号（去末尾 `U+6 位数字`） |
| 中文品名 | 中文品名 | → 货物描述（品名+数量PCS） |
| 货箱重量 | 货箱重量 | → 总公斤数 |
| 总箱数 | 总箱数 | → 总包装数量 |
| 申报总数量 | 申报总数量 | → 货物描述中的数量 |
| 总申报货值 | 总申报货值 | → 货值 |
| 申报币种 | 申报币种 | → 币种（代码转中文） |
| 客户渠道 | 客户渠道 | → 判断是否「全美锁仓」 |

> 「总箱数」表头可能带括号说明（如 `总箱数(CTN)`），`startsWith` 匹配兼容。

## 4. 核心字段规则

### 4.1 货物描述

按 SO 聚合「中文品名 + 申报总数量」：同一 SO 内相同品名数量累加，多品名以「、」连接。

- 格式：`品名+数量PCS`（`PCS` 大写，`+` 连接）
- 示例：`氛围灯+336PCS` / `夜灯+64PCS、氛围灯+64PCS`

### 4.2 备注（仅「全美锁仓」渠道）

触发条件：客户渠道含「全美」。文案模板（仓库代码替换 AAAA）：

```
本保单承保AGL（亚马逊物流）承运的物流运输服务，其亚马逊货件建仓地址为“{仓库代码}”，投保的目的地为“{仓库代码}”，同时存在最后FBA调仓可能{仓库代码}
```

> 注意：前两处仓库代码用中文全角引号 `“”` 包裹，第三处**不加引号**。

### 4.3 币种

申报币种代码 → 中文名。映射：`USD→美元`、`EUR→欧元`、`GBP→英镑`、`JPY→日元`、`CNY/RMB→人民币`、`AUD→澳元`、`CAD→加元`、`HKD→港币`、`KRW→韩元`、`SGD→新加坡元`、`CHF→瑞士法郎`、`MXN→墨西哥比索`、`AED→迪拉姆`。未知代码原样返回。

### 4.4 入仓编号

FBA ID 去掉末尾 `U+6 位数字` 箱序后缀，如 `FBA19MXX2JCWU260101` → `FBA19MXX2JCW`。

## 5. 配置项

| 字段 | 必填 | 默认值 | 选项/说明 |
|------|------|--------|----------|
| 起运日期 shipDate | 是 | — | YYYY-MM-DD（date input） |
| 干线运输方式 transportMode | 否 | 海运 | 海运/空运/铁路/公路/全程快递/多式联运 |
| 派送方式 deliveryMethod | 否 | 卡车派 | 卡车派/快递派/待定 |
| 起运地 originPlace | 否 | 深圳 | 文本 |
| 货物类别 goodsCategory | 否 | 无易碎品 | 无易碎品/是易碎品 |
| 包装类型 packageType | 否 | 纸箱 | 纸箱/木箱/木箱+纸箱/托盘/航空箱/集装箱 |

## 6. API 接口

### POST `/api/kuajingbao-insurance`

- **输入**: `multipart/form-data`，字段 `file` + 配置字段（shipDate/transportMode/deliveryMethod/originPlace/goodsCategory/packageType）
- **校验**: `.xlsx` / `.xls`；shipDate 必填（缺失返回 400「请填写起运日期」）
- **输出**: JSON `{ sessionId, sourceFile, outputName, totalGroups, lockWarehouseCount, groups[], downloadUrl }`
  - `groups[]` 每项: `{ so, country, warehouseCode, goodsDescription, currency, totalValue, totalBoxes, totalWeight, remark }`
  - `lockWarehouseCount`: 全美锁仓（带备注）票数

### GET `/api/kuajingbao-insurance?session=xxx`

- 返回生成的 `.xlsx` 文件（`Content-Disposition` 带 UTF-8 `filename*`）
- **过期**: session 30 分钟无访问自动清除

## 7. 已知限制

- 仅处理货箱清单第一个 sheet（`worksheets[0]`），忽略其他 sheet
- 输出保留模板的 500 行数据区结构（R1 表头 + R2 说明 + R3 起数据），数据行之后不留示例数据
- 币种未知代码不做中文映射，原样输出
- 备注仅对「全美锁仓」渠道（客户渠道含「全美」）生成，其余渠道留空
