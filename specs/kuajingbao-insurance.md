# 跨境堡批量投保 — 功能规格文档

> 最后更新: 2026-10-22 | 维护者: berry-bi

## 1. 功能概述

**跨境堡批量投保**（`/kuajingbao-insurance`）将「系统导出的货箱清单」按 SO 号（系统SO）自动聚合，填充「跨境堡批量投保箱单模版」，消除手动整理货物描述、货值、币种、备注的重复劳动。

- **输入**: 系统导出的货箱清单 Excel（`.xlsx` / `.xls`，Sheet1，含「系统SO」+「中文品名」表头）
- **输出**: `{原文件名}_跨境堡投保箱单.xlsx`，主 sheet「批量导入投保数据」逐票（SO）一行

### 审核功能（2026-10 新增）

生成的同时做三项审核，结果在页面醒目展示、**不阻断下载**（人工核对后自行处理）：

1. **易碎品拆分**：按「材质」判定易碎（玻璃/陶瓷/大理石/水晶/亚克力及其制品），一票内同时含易碎与非易碎时**自动拆成两票**投保。
2. **币种校验**：按目的国预期申报币种（如德国→EUR）与清单申报币种比对，不一致时告警（疑似客户填错币种）。
3. **FBA 仓校验**：入仓编号不含「FBA」字眼时判定为疑似非 FBA 仓（卫星仓/沃尔玛仓）告警。

| 国家 | 国家 | → 目的国 |
| 仓库代码 | 仓库代码 | → 目的地 / 备注中的 AAAA |
| FBA ID | FBA ID / FBA | → 入仓编号（该票全部 FBA 去重后以空格连接，见 §4.4） |
| 中文品名 | 中文品名 | → 货物描述（品名+数量PCS） |
| 货箱重量 | 货箱重量 | → 总公斤数（合并单元格总值，仅作无按行重量时的兜底） |
| 总箱数 | 总箱数 | → 总包装数量（逐行累加） |
| 申报总数量 | 申报总数量 | → 货物描述中的数量 |

## 4. 核心字段规则

### 4.1 货物描述

按 SO 聚合「中文品名 + 申报总数量」：同一 SO 内相同品名数量累加，多品名以「、」连接。

- 格式：`品名+数量PCS`（`PCS` 大写，`+` 连接）
- 示例：`氛围灯+336PCS` / `夜灯+64PCS、氛围灯+64PCS`

### 4.2 备注

备注由两部分组成，两者同时存在时以「；」连接：

1. **全美锁仓说明**：客户渠道含「全美」时生成。文案模板（仓库代码替换 AAAA）：

```
本保单承保AGL（亚马逊物流）承运的物流运输服务，其亚马逊货件建仓地址为“{仓库代码}”，投保的目的地为“{仓库代码}”，同时存在最后FBA调仓可能
```

> 注意：仓库代码只出现在前两处（「建仓地址为“X”」「投保的目的地为“X”」），用中文全角引号 `“”` 包裹；结尾「同时存在最后FBA调仓可能」**不带仓库代码**。

2. **入仓编号溢出**：入仓编号超过 350 字符时，多余 FBA 号写入备注。格式：`入仓编号超出350字符，多余FBA：{FBA1} {FBA2} …`（空格连接）。

### 4.3 币种

申报币种代码 → 中文名。映射：`USD→美元`、`EUR→欧元`、`GBP→英镑`、`JPY→日元`、`CNY/RMB→人民币`、`AUD→澳元`、`CAD→加元`、`HKD→港币`、`KRW→韩元`、`SGD→新加坡元`、`CHF→瑞士法郎`、`MXN→墨西哥比索`、`AED→迪拉姆`。未知代码原样返回。

### 4.4 入仓编号

该票（同一 SO）下所有 FBA ID：先去掉末尾 `U+6 位数字` 箱序后缀（如 `FBA19MXX2JCWU260101` → `FBA19MXX2JCW`），去重、保持出现顺序，再用空格连接。

> FBA ID 是**逐行**属性：拆分易碎/非易碎两票时，每票只填自己那几行对应的 FBA 号（见 §4.5），不填整票 FBA。

- 例：一票有 4 个 FBA → `FBA19PSTWW0W FBA19PSTRTDP FBA19PSSTMDV FBA19PSQHRHP`
- **字数上限 350 字符（含分隔符）**：从第一个 FBA 开始逐个累加（连分隔符一起算），一旦加入下一个会超过 350 就停止；溢出的 FBA 号**按完整 FBA 号为单位**整段挪到备注（见 §4.2），绝不把单个 FBA 号从中间拆成两半。

### 4.5 易碎品拆分（审核 a）

按「材质」判定易碎：材质含以下关键词（中文或英文，大小写不敏感）即视为易碎，其余为非易碎。

- 关键词：`玻璃` / `陶瓷` / `大理石` / `水晶` / `亚克力` / `glass` / `ceramic` / `marble` / `crystal` / `acrylic`
- 「及其制品」无需单独列举：`玻璃制品`/`陶瓷制品` 等已含关键词本身。

判定规则：

- 一票（SO）内**全部易碎** → 单票，货物类别 `是易碎品`。
- 一票内**全部非易碎** → 单票，货物类别 `无易碎品`。
- 一票内**同时含易碎与非易碎** → 拆成两票：`{SO}-1`（易碎品，货物类别 `是易碎品`）、`{SO}-2`（非易碎品，货物类别 `无易碎品`）。易碎始终为 `-1`、非易碎始终为 `-2`，与源数据行序无关。

拆分的两票按行各自聚合：货值、总箱数按行累加；公斤数按行（单箱毛重×总箱数）累加；货物描述只含该侧品名；**入仓编号只含该侧各行对应的 FBA 号**（FBA ID 是逐行属性，随材质归到对应子票，不再取整票 FBA）；备注（全美锁仓说明）两侧一致（同一票物理货件）。

### 4.6 币种校验（审核 b）

按「目的国 → 预期申报币种代码」映射表（`COUNTRY_CURRENCY`）比对清单申报币种。覆盖主要目的国；**不在表中的国家不校验**。

- 例：德国预期 `EUR`，清单申报 `USD` → 告警「德国：申报 USD，正常应为 EUR」。
- 欧盟内非欧元区国家单独列出（波兰 PLN / 捷克 CZK / 匈牙利 HUF / 罗马尼亚 RON / 瑞典 SEK / 丹麦 DKK）。
- 申报币种为空时不校验。告警仅提示，不阻断。

### 4.7 FBA 仓校验（审核 c）

入仓编号（去箱序后缀后）**不含 `FBA` 字眼**（大小写不敏感）→ 判定为疑似非 FBA 仓，告警。

- 例：`STAR-SBCVDCB3G5W5E`（卫星仓）不含 FBA → 告警「疑似卫星仓 / 沃尔玛仓等非 FBA 仓」。
- 告警仅提示，不阻断；原入仓编号照常写入（人工决定是否剔除）。

## 6. API 接口

### POST `/api/kuajingbao-insurance`

- **输入**: `multipart/form-data`，字段 `file` + 配置字段（shipDate/transportMode/deliveryMethod/originPlace/packageType）
- **校验**: `.xlsx` / `.xls`；shipDate 必填（缺失返回 400「请填写起运日期」）
- **输出**: JSON `{ sessionId, sourceFile, outputName, totalGroups, lockWarehouseCount, currencyWarnings[], nonFbaWarnings[], splitInfos[], groups[], downloadUrl }`
  - `groups[]` 每项: `{ so, orderNo, country, warehouseCode, goodsDescription, goodsCategory, isFragile, currency, currencyCode, totalValue, totalBoxes, totalWeight, remark }`
  - `lockWarehouseCount`: 全美锁仓（带备注）票数
  - `currencyWarnings[]`: 币种异常 `{ so, country, declared, expected }`
  - `nonFbaWarnings[]`: 疑似非 FBA 仓 `{ so, fbaCodes[] }`
  - `splitInfos[]`: 被拆分的 SO `{ so }`

### GET `/api/kuajingbao-insurance?session=xxx`

- 返回生成的 `.xlsx` 文件（`Content-Disposition` 带 UTF-8 `filename*`）
- **过期**: session 30 分钟无访问自动清除

## 7. 已知限制

- 仅处理货箱清单第一个 sheet（`worksheets[0]`），忽略其他 sheet
- 输出保留模板的 500 行数据区结构（R1 表头 + R2 说明 + R3 起数据），数据行之后不留示例数据
- 币种未知代码不做中文映射，原样输出
- 入仓编号最多 350 字符（含分隔符），超出部分（多余 FBA 号）进备注；多个 FBA 以空格连接
- 材质列缺失时解析报错（易碎判定依赖「材质」列，见 §4.5）
- 总公斤数按「单箱货物毛重×总箱数」按行累加，与合并单元格的「货箱重量」总值可能因四舍五入有微小差异（如 22.9 vs 23.0），两者不一致时以按行计算结果为准
- 币种校验仅覆盖 `COUNTRY_CURRENCY` 映射表内的国家，未覆盖的国家不校验
- 易碎判定为关键词子串匹配，含「玻璃/陶瓷」等字样的特殊品名可能被误判为易碎（如「玻璃纤维」），此类需人工复核
