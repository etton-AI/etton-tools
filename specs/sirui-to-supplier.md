# 思锐转供应商发票 — 功能规格文档

> 最后更新: 2026-11-10 | 维护者: berry-bi

## 1. 功能概述

**思锐转供应商发票**（`/sirui-to-supplier`）把思锐客户的「下单发票」自动转换为供应商下单模板，消除手动粘贴的重复劳动。支持 **4 家供应商：华威尔 / 美琦 / 英美 / 航乐**。

- **输入**: 思锐客户下单发票 Excel（`.xlsx`，sheet「ETTON电商物流 下单模板」），**可批量一次上传多份**
- **界面输入**: 供应商（下拉）、渠道（可搜索下拉，按供应商从模板读取）、报关方式（可选覆盖）、送货货站/交货仓库（可选覆盖）、每文件独立客户订单号（批量时每份一个 SO 输入框，可留空）
- **输出**: ZIP 包，含 N 份供应商下单发票（`<客户订单号 或 源文件名>.xlsx`）；华威尔 / 美琦 / 航乐自动嵌入产品图片

## 3. 供应商模板与映射

内置模板 `public/templates/sirui-suppliers/`：`华威尔-模板.xlsx`、`美琦-模板.xlsx`、`英美-模板.xlsx`、
`英美-美国模板.xlsx`、`航乐-模板.xlsx`。

### 3.1 公共规则

- **混箱语义**：G 列箱数 `>=1` 开 G 个新箱（单箱数量 = 总数量 ÷ 箱数）；G `=0/空` 表示**混箱**（共享当前箱，单箱数量 = 总数量）
- **华威尔 / 航乐 = 一箱一行（explode）**：每物理箱生成一行，混箱行共享当前箱序号
- **美琦 / 英美 = 排序号**：累计区间 `"起-止"`（单箱时一个数字），混箱共享当前累计箱号
- **单箱数量** = 总数量 ÷ 箱数（`clean()` 去浮点噪声）
- **单个产品净重** = 单箱净重 ÷ 单箱数量（华威尔 / 航乐）
- **报关方式**：有单证 → 各供应商「单独报关/一般贸易/报关退税」；无单证 → 「买单报关/代理报关/买单报关/委托报关」（华威尔/美琦/英美/航乐）。用户可手动覆盖为各供应商下拉值域内的任意值
- **清关方式**：华威尔 D3（自税/不包税→不包税，其余→包税）、英美 B18（包税→否，其余→是）、航乐 L7（自税→不包税递延，不包税→不包税，其余→包税）
- **尺寸继承**：混箱行源尺寸留空 → 继承当前箱尺寸；源尺寸非空 → 用自身尺寸（英美混箱行源尺寸留空，美琦混箱行已填）
- **浮点计算**统一 `clean()`（`toPrecision(15)`）去噪，对齐 Excel/WPS 精度（14.7/12 → 1.225 而非 1.2249999…）
- **数据区填充**：华威尔 / 美琦 / 航乐 explode/排序号行数超模板预留行时 `duplicateRow` 扩行；英美双模板各自覆盖式填充

### 3.2 华威尔（发票箱单 sheet，数据区 R18 起，22 列）

- **一箱一行**，箱唛号 = `货箱编号` + `U` + 两位递增序号（跨全部箱累计 `U01`…`U21`，混箱共享当前序号）
- 顶部：B1 客户原单号、B2 交货仓库（默认福永仓）、D2 是否购买保险、B3 交货客户代号（固定 `HW01870`）、D3 清关方式、B4 走货线路、B5 报关方式、B6 目的地/国家、B7 地址类型（固定「商业地址」）、B8 收货地址名称、B9 收件公司、B10 收件人、B11 联系电话、B12 邮编、B13 省份/州、B14 城市、B15 收件地址、B16 总件数
- 数据列 A–V：箱唛号 / Reference ID / 中文品名 / 英文品名 / 材质 / 用途 / 海关编码 / 产品类型(固定「普货」) / 单箱产品数量 / 箱数(固定 1) / 币种 / 单个产品申报单价 / 单个产品净重 / 图片(DISPIMG，N 列) / 品牌 / 品牌类型 / 型号 / 销售链接(空→0) / 备注(空) / 总产品数量 / 总申报金额 / 毛重
- **图片**：源为 WPS DISPIMG（`xl/cellimages.xml` + `xl/media/`），注入时按图片 buffer hash 去重

### 3.3 美琦（发票 sheet，数据区 R19 起，19 列）

- **排序号**（累计区间），单箱/混箱均为**字符串**（如 `"21"` / `"25-29"`）
- 顶部：B1 客户订单号、B2 客户参考号、B3 服务、B5 收件人姓名、B6 地址一、B7 城市、B8 省/洲、B9 邮编、B10 国家代码、B11 电话、B12 邮箱、B13 公司、B14 带电、B15 带磁、B16 报关方式、B17 箱数、F1 预计交货站点（默认中山仓）、F3 提货方式（固定「自送货」）
- 数据列 A–S：排序号 / 英文品名 / 中文品名 / 产品性质(固定「普货」) / 单箱数量 / 单价(美金) / 货箱重量 / 长−1 / 宽−1 / 高−1 / 海关编码 / 品牌 / 材质 / 型号 / 用途 / 图片(DISPIMG，P 列) / PO Number / 物品箱号 / 物品FBA ID
- **长/宽/高 = 源值 − 1**（美琦特有）
- **物品箱号（R 列）= 源 G 列箱数原样透传**（混箱/空 → 0，非 1）
- **材质（M 列）如实透传源 E 列**：答案样本的材质列为模板示例值（「铁+ABS塑料材质」/「铁+ABS」），是作者制作答案时未覆盖的手工瑕疵，本实现透传源真实材质（不锈钢铝合金/铝合金/碳纤维）

### 3.4 英美（模板 sheet，数据区 R26 起，按目的地国家自动切换模板）

英美有**两个模板**，按源发票「收件人国家」自动选择：

| 目的地 | 模板文件 | 数据区列数 | 顶部字段 |
|--------|----------|-----------|----------|
| 英欧（默认，非 US）| `英美-模板.xlsx` | 26 列（A–Z）| B1 服务、B14 客户订单号、B15 带电、B16 带磁、B17 报关、B18 清关、B19 VAT、**B20 EORI**、B21 币种、B22 所在货站、B24 箱数 |
| 美线（US / USA）| `英美-美国模板.xlsx` | 24 列（A–X）| B1 服务、B14 客户订单号、B15 带电、B16 带磁、B17 报关、B18 清关、B19 VAT、**B20 币种（无 EORI）**、B24 箱数 |

- **排序号**（累计区间），单箱/混箱为**数字**（`8` / `9`），区间为字符串（`"1-2"` / `"3-5"`）——与美琦字符串约定不同，对齐各自答案样本
- 地址块 B2–B13：模板为 VLOOKUP（按 B2 地址库编码带出），商业/私人地址需**清空 B2 并手动填入**收件信息（空值也显式写 `null`，否则 VLOOKUP 公式不会被清除）
- 数据列 A–U：排序号 / PO Number(空→0) / 货箱重量 / 长 / 宽 / 高 / 产品SKU / 中文品名 / 英文品名 / 单价 / 数量 / 材质 / 海关编码 / 用途 / 品牌 / 型号 / 销售链接 / 销售价格(空) / 图片链接(空) / 重量(空) / ASIN

### 3.5 航乐（Packing list装箱单发票 sheet，数据区 R12 起，24 列）

- **非FBA 一箱一行**，Box No 顺序 1..N，混箱尺寸继承当前箱
- 顶部：B3 收件地址、G3 国家、B4 ZIP、D4 公司、G4 电话、B5 城市、D5 收件人、G5 邮箱、I5 报关类型、K5 交货仓库（默认中山航乐仓）、B7 公司名称、I7 渠道、L7 是否包税、B8 VAT号、B9 EORI号、B10 VAT注册地址（换行转空格）
- 数据列 A–X：Box No / 中文品名 / 英文品名 / 材质(中) / 材质(英) / 海关编码 / 型号 / 品牌 / 用途 / 单箱数量 / 总数量 / 净重(单个=净重÷单箱数量) / 实重 / 单价 / 总价 / 长 / 宽 / 高 / **材重(长×宽×高÷6000)** / **CBM(长×宽×高÷1e6)** / 带电 / 带磁 / 图片(DISPIMG，W 列) / 销售链接
- 数据区固定 12 行（R12~R23），R24 合计行（`SUM(K)/SUM(M)/SUM(O)/SUM(S)/SUM(T)` 自动求和）

## 4. 渠道 / 货站 / 报关下拉（从供应商模板读取，单一数据源）

| 供应商 | 渠道 sheet | 列 | 货站/交货仓库 |
|--------|-----------|-----|--------------|
| 华威尔 | 走货线路名和申报币别要求-不能删 | A 列（R2 起） | 硬编码 HUAWEI_STATIONS |
| 美琦 | 服务渠道 | B 列（R2 起） | 硬编码 MEIQI_STATIONS |
| 英美 | 渠道列表（英欧 B 列）+ 渠道组（美线 A 列，双模板合并）| — | 从模板「站点」sheet A 列读取 |
| 航乐 | —（渠道 sheet 在模板中）| — | 硬编码 HANGYUE_STATIONS |

- 报关方式下拉值域与各模板 data validation 一致：华威尔 `单独报关/买单报关/合并单独报关`、美琦 `一般贸易/代理报关/手册报关/9710电商深圳报关单一窗口/9810报关`、英美 `报关退税/买单报关/合并报关`、航乐 `报关退税/委托报关`

## 5. 图片处理（华威尔 / 美琦 / 航乐）

- 华威尔 / 美琦源用 WPS DISPIMG（`xl/cellimages.xml` + `xl/media/` + `xl/_rels/cellimages.xml.rels`），注入时按图片 buffer hash 去重（同一产品多箱共用一张图）
- 航乐源用浮动图片（`xl/drawings/drawing1.xml`）
- 英美无图片列

## 6. API 接口

### POST `/api/sirui-to-supplier`

- **输入**: `multipart/form-data`：`file`（可多个）、`supplier`（必填）、`channelName`（必填）、`customerOrderNo`（可多个，与 file 顺序对齐）、`customsOverride`（可选）、`station`（可选）
- **输出**: JSON `{ sessionId, result }`，`result` 含 `{ zipFileName, supplier, channel, total, files[], downloadUrl }`；`files[]` 每项 `{ sourceFile, outputFile, customerOrderNo, totalBoxes, dataRows, warnings }`
- **限制**: `bodyParser.sizeLimit = "50mb"`

### GET `/api/sirui-to-supplier?session=xxx`

- 下载转换结果 ZIP（`application/zip`，`Content-Disposition` 含 UTF-8 文件名）；session 30 分钟无访问自动清除

### GET `/api/sirui-to-supplier/channels?supplier=xxx`

- 返回 `{ supplier, channels[] }`，渠道清单供前端下拉

### GET `/api/sirui-to-supplier/options?supplier=xxx`

- 返回 `{ supplier, customs[], stations[] }`：报关方式下拉值域 + 送货货站/交货仓库列表

## 7. 已知限制 / 非目标

- 客户订单号（SO）**每文件一个输入框**，可留空（留空按源文件名命名）
- 英美渠道下拉合并双模板清单，由用户按目的地自选匹配渠道；转换时模板按源「收件人国家」自动切换
- 华威尔「目的地/国家」默认「美东」，需人工核对收货州属东/中/西岸后修改（转换写 `warnings[]` 提醒）
- 华威尔 / 美琦 / 航乐「收货地址」为人工输入值（非 FBA 无地址库可带出）
- 英美「所在货站」默认留模板值，用户可从「站点」sheet 手动覆盖
- 仅处理「ETTON电商物流 下单模板」sheet；未找到有效箱单数据时报错
- 航乐数据区固定 12 行（R12~R23），单票 SKU 行数须 ≤ 12，超出报错「请拆分发票」
- 航乐材重/CBM 为**真实计算值**（长×宽×高÷6000 / ÷1e6），与答案样本的 1.0 占位值有意不同（答案样本未填）
